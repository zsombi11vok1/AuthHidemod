# AuthHide

A project is build-ready with Fabric Loom.

## Build

1. Install JDK 21.
2. Open this folder in IntelliJ IDEA and let Gradle import finish.
3. Run the Gradle task `build`.

The built mod jar will appear in `build/libs/`.

## Notes

- Minecraft target: 1.21.11
- Client-only mod
- Command: `/authhide`
